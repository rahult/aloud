# Chirp — Design Context

## Users

Privacy-conscious developers and power users who want neural text-to-speech
without cloud services. Chirp runs as a tiny local HTTP service and a menu-bar
desktop app; its web UI is opened briefly to preview voices, tweak settings,
and grab a WAV. The job to be done: type text → hear it → save it, in seconds,
with zero setup. Many users arrive via Margin (the reading app it was
extracted from).

## Brand Personality

Quiet, crafted, warm. Three words: **warm, precise, unhurried**. Chirp is a
tool that respects the machine it runs on — "nothing leaves this machine" is
both a technical fact and the emotional core (calm, trust). It should feel
like a well-made studio instrument, not a dashboard.

## Aesthetic Direction

- Warm-dark "paper and ink" palette, already established across the product
  site and app: near-black `#141311`, warm paper ink `#e8e4dc`, restrained
  amber `#c9a86a`, hairline borders `#3a362f`.
- Serif display (Georgia/system serif) for the wordmark and headings;
  system sans for UI text. No webfont downloads — the app is local-first and
  must render identically offline.
- Anti-references: SaaS dashboards, gradient text, glow/neon-on-dark,
  glassmorphism, card-in-card grids, anything that looks like a template.
- Amber is an accent, not a theme: used for one primary action and small
  moments of emphasis only.

## Design Principles

1. **Best defaults, honest settings** — the app works perfectly with zero
   configuration (Heart voice, 1× speed). Every setting is persisted, legible,
   and reversible; advanced controls are disclosed progressively, never
   hidden behind modals.
2. **Restraint over decoration** — hairlines, spacing, and typography do the
   work. No shadows, glows, gradients, or decorative icons.
3. **State is always visible** — model warm-up, generation, playback, and
   errors are surfaced inline in plain language; never a blocking alert.
4. **Keyboard-first** — Cmd/Ctrl+Enter speaks; every control is reachable and
   visibly focused.
5. **Local means fast and offline-safe** — system font stacks, no external
   requests, optimistic UI.
